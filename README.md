# Império da Face - Site de Harmonização Orofacial

Este é o site oficial do Império da Face, especializado em harmonização orofacial com foco em procedimentos labiais.

## Estrutura do Projeto

- `index.html` - Página principal do site
- `styles.css` - Estilos do site
- `script.js` - Funcionalidades JavaScript
- `hero-bg.jpg` - Imagem de fundo da seção hero (a ser adicionada)

## Funcionalidades

- Design responsivo
- Navegação suave entre seções
- Formulário de contato
- Seções informativas sobre serviços
- Menu de navegação fixo

## Como Executar

1. Clone este repositório
2. Abra o arquivo `index.html` em seu navegador
3. Para desenvolvimento, recomenda-se usar um servidor local

## Personalização

- Para alterar as cores principais, edite as variáveis no arquivo `styles.css`
- Para adicionar novas seções, copie a estrutura existente no `index.html`
- Para modificar o formulário de contato, ajuste o código em `script.js`

## Requisitos

- Navegador moderno com suporte a HTML5 e CSS3
- JavaScript habilitado
